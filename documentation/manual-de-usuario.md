# Manual de Usuario

Esta guía resume el acceso y uso básico de NexusDesk para los usuarios del sistema.

### 1. Acceso al sistema

1. Abre la aplicación web de NexusDesk en el navegador.
2. Ingresa tus credenciales en la pantalla de inicio de sesión (`Login`).

### 2. Uso básico de la mesa de ayuda

* Panel / Vista principal: Consulta el estado general y las opciones disponibles según tu rol `[completar según las vistas reales de la aplicación]`.
* Gestión de solicitudes / tickets: Crea nuevas solicitudes o revisa el seguimiento de las existentes completando los campos requeridos `[ajustar según el flujo real del proyecto]`.
* Cierre de sesión: Finaliza la sesión cuando termines de utilizar el sistema.
